# 微信公众号文章抓取工具 — 使用指南

## 环境要求

- Python 3.10+
- 一个微信公众号后台账号（个人订阅号即可，免费注册：https://mp.weixin.qq.com）

## 第一步：安装依赖

```bash
pip install -r requirements.txt
```

国内镜像加速：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn
```

## 第二步：获取认证参数

登录 https://mp.weixin.qq.com 后，按以下方式获取三个参数：

### 1. Cookie

| 步骤 | 说明 |
|------|------|
| F12 打开开发者工具 | 选择 **Network**（网络）标签 |
| 触发 appmsg 请求 | 左侧菜单点「素材管理」→「已发表内容」 |
| 找到 appmsg 请求 | Network 面板搜索框输入 `appmsg` |
| 复制 Cookie | 点击该请求 → Headers → Request Headers → **Cookie** 那行，双击全选复制 |

### 2. Token

| 步骤 | 说明 |
|------|------|
| 同上 appmsg 请求 | 点击该请求 |
| 查看 Payload | 右侧切换到 **Payload** / **Parameters** 标签 |
| 复制 Token | 在 Query String Parameters 区找到 **token**，复制那串数字 |

### 3. Fakeid

| 步骤 | 说明 |
|------|------|
| 打开目标公众号任意文章 | 浏览器中打开「银河系漫游客」的任意一篇文章 |
| F12 → Elements | 按 Ctrl+F 搜索 `var biz` |
| 复制 Fakeid | 复制 `var biz = "..."` 中引号内的 Base64 字符串 |

## 第三步：配置 .env

将 `.env.example` 重命名为 `.env`，填入参数：

```
WEIXIN_COOKIE=你的完整Cookie
WEIXIN_TOKEN=你的token数字串
WEIXIN_FAKEID=你的fakeid
TARGET_NAME=银河系漫游客
MAX_ARTICLES=50
REQUEST_INTERVAL=12
OUTPUT_DIR=output
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| TARGET_NAME | 公众号名称，决定输出目录名 | - |
| MAX_ARTICLES | 抓取文章数量上限 | 50 |
| REQUEST_INTERVAL | 请求间隔（秒），太短可能触发风控 | 12 |
| OUTPUT_DIR | 输出根目录 | output |

## 第四步：运行

```bash
python main.py
```

运行过程分三步：

```
Step 1/3: 拉取文章列表    → 分页请求，按间隔等待
Step 2/3: 下载文章内容    → 逐篇下载、清洗 HTML、下载图片
Step 3/3: 生成索引页      → 生成 index.html
```

完成后自动在浏览器打开目录索引页。

## 输出说明

```
output/银河系漫游客/
├── index.html              # 目录索引页（点击标题阅读离线文章）
├── articles_metadata.json  # 元数据（供二次利用）
└── articles/
    └── 2025-01-15_标题/
        ├── 2025-01-15_标题.html   # 离线文章（含图片）
        └── images/
            ├── img_001.jpg
            └── img_002.png
```

- **index.html**：按发布时间倒序排列的目录表格，点击标题即可本地阅读
- **每篇文章 HTML**：自包含，保留原文完整格式，图片已本地化，无网络也可打开
- **articles_metadata.json**：结构化数据，方便后续搜索、分析、转档

## 常见问题

### Cookie/Token 过期

运行时报错 `鉴权失败`，需重新获取。Cookie 通常数小时到一天内失效，Token 随页面刷新变化。

### 文章数量少于预期

- 该公众号历史文章总数可能不足 50 篇
- 可在 `.env` 中增大 `MAX_ARTICLES` 重试

### 某些文章下载失败

可能原因：文章已被删除、网络超时、链接失效。脚本会自动跳过并记录日志，不影响整体流程。
